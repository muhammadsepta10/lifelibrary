# Next.js PWA di Vercel free + Postgres Neon, satu akun Pemilik

Aplikasi berupa PWA Next.js (kode dijaga agnostik terhadap platform), di-deploy ke Vercel free tier, dengan database Postgres managed (Neon free tier). Karena URL-nya publik, semua halaman pengelolaan dilindungi login satu akun Pemilik. PWA dipilih supaya kamera HP bisa dipakai untuk scan barcode tanpa perlu aplikasi native, dan scanner USB tetap bisa dipakai karena bekerja sebagai input keyboard.
